# Legacy Trailer Rentals LLC - Visual MVP Homepage Demo

Polished, mobile-first homepage concept demo for **Legacy Trailer Rentals LLC** in **Madera, California**.

## Overview

This project is a **front-end visual MVP concept** designed to demonstrate:
- Proposed brand styling, contrast, and typography
- Conversion-focused 13-section homepage flow
- Interactive trailer fleet catalog preview (search, category filtering, multi-photo modal preview, and trailer-to-booking pre-selection)
- Mobile-first experience with compact menu drawer and sticky bottom action bar (`View Trailers` / `Book Now`)
- Interactive 3-step trailer booking flow (Booking Details -> Sign Trailer Contract -> Mock Online Payment)
- Mock Admin Dashboard at `/admin` with local browser persistence

## Demo Boundaries

- **No backend or database**: No Supabase, server authentication, or real payment processing are active in this demo.
- **Honest placeholders**: All trailer names, specifications, rates, policies, unverified contact details, and surrounding service areas are clearly labeled as placeholders until supplied by the business owner.

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.
